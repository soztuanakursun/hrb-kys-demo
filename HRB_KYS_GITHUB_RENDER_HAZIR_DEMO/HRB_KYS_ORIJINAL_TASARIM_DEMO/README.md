# HRB KYS — Orijinal Tasarım Temalı Kurgusal Demo

Bu paket, yüklenen `Kalite_Yonetim_Sistemi_Nihai (2) (1).html` dosyasındaki **CSS tema, yatay menü, üst başlık, kart ve tablo stillerini** alır ve daha önce Render üzerinde çalışan demo API’sine bağlar.

**Sınır:** Orijinal HTML'nin tüm sayfa davranışları birebir taşınmadı. Önceki demo işlevleri (giriş, departman yetkileri, örnek PDF, revizyon talepleri) mevcut `bridge.js` ile çalışır. Gerçek dokümanlar, kullanıcı verileri ve gömülü PDF arşivi bu pakette **yoktur**.

GitHub’da mevcut `HRB_KYS_GITHUB_RENDER_HAZIR_DEMO/` klasörünün içindeki `static/index.html` dosyasını bununla değiştirin. Aynı klasördeki diğer dosyaları koruyun. Render otomatik deploy başlatabilir.

Ücretsiz Render diski kalıcı değildir; demo verileri yeniden başlatıldığında kaybolabilir.
